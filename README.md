# Simple-Budget-Tracker
My first attempt at creating a workable budget tracker using Python. As of the current version, this tool reads expenses from a CSV file and summarizes total spending with category breakdowns.
Future planned upgrades include an income tracker, monthly breakdowns, as well as a detailed dashboard with charts.

## Features
- Reads budget data from CSV
- Calculates total spending
- Groups spending by category

## How to use
1. Enter monthly expenses in `budget.csv`
2. Run: 'budget-tracker.py'

## Example Output

TOTAL SPENDING: 4100

BY CATEGORY:
Food : 2000
Transport : 500
Bills : 600
